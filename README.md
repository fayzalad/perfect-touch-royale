# Perfect Touch Royale

Welcome to the official repository for **Perfect Touch Royale**, a bespoke e-commerce store bringing authentic Turkish women's fashion to Nigeria.

## Website
View the live store here: [https://fayzalad.github.io/perfect-touch-royale/](https://fayzalad.github.io/perfect-touch-royale/)

## Overview
This platform provides a curated shopping experience for high-quality Turkish garments, including:
- **Abayas, Kaftans, and Evening Dresses**: Hand-picked from ateliers in Istanbul.
- **Tailored Shopping Experience**: Interactive color/size selection and quick-view functionality.
- **Concierge Service**: Direct WhatsApp order integration for personalized styling and consultation.
- **Logistics**: Nationwide delivery across all 36 Nigerian states and the FCT, with international shipping options.
- **Support**: Dedicated size guides, care instructions, and flexible exchange policies.

## Technical Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Deployment**: Static site deployment to GitHub Pages via local build (no cloud runners required).

## Development
To run this project locally:

1. Clone the repository.
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Start the development server:
   ```bash
   pnpm run dev
   ```

## Deployment
This project uses a custom deployment script to publish directly to the `gh-pages` branch. To deploy changes:
```bash
pnpm run deploy
```
